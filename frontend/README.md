# HungerHaven frontend

React (Create React App) frontend for HungerHaven. See the [root README](../README.md) for
full project setup instructions.

## Available scripts

- `npm start` — runs the app in development mode at `http://localhost:3000`
- `npm run build` — builds the app for production into the `build/` folder
- `npm test` — runs tests

## Configuration

The backend API base URL is set in `src/config.js` and defaults to `http://localhost:5000`.
Override it by setting `REACT_APP_API_BASE_URL` in a `.env` file in this folder.
